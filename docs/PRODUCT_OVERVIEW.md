# Product Overview

Price-Matic is a mobile appliance marketplace for Pakistan, built with React Native and Expo. Users browse and compare new appliances by brand, explore a second-hand marketplace, and get ML price estimates for used items.

## Core features

**Browse and discover.** A home screen shows featured brands in a grid, popular appliances, and promotional banners. Users search, filter a brand's catalogue by appliance category, and view product pages with specifications, key features and an image gallery.

**Compare and reviews.** The side-by-side comparison view shows all specs for two appliances, with automatic highlighting of key differences. Users read reviews from the community or leave their own ratings and feedback.

**Second-hand marketplace.** Browse used appliances from other users with photos, condition details, and seller information. Direct chat with sellers for negotiation and coordination.

**Sell your appliance.** A dedicated form lets users list used items with photos, condition, and asking price. The "My Ads" section shows all personal listings with edit and delete options.

**Price valuation.** The app includes an ML-powered price estimator: users enter an appliance's brand, condition, type, working status, age and warranty status, and receive a predicted market price for their item.

## Screens and navigation

Thirty routes cover authentication (welcome, login, sign-up), home, brand and appliance details, reviews, comparison, the used marketplace, listing creation and management, one-to-one messaging, user profile, price valuation, and an admin dashboard for inventory management.

## Technical note

The demo build runs on locally seeded fictional data to simulate the full experience without requiring live cloud services. All screenshots use fictional demo data.
